Share Files via QR Code - Instantly

Share files instantly via QR code with optional password protection and auto-expiry. No sign-up required.

Why this? Sharing a file from your desktop to your phone was always a hassle - cables, WhatsApp to yourself, email. QR File Share removes that friction entirely. Upload once, scan, done.
Download Extension View on GitHub

Any File, Up to 50MB

PDFs, images, documents - share anything in seconds directly from Chrome.

Password Protection

Optionally protect your file with a password. BCrypt-hashed, never stored in plain text.

Auto-Expiry

Files automatically delete after 1 hour, 6 hours, 24 hours, or 7 days - your choice.

Private Storage

Files are stored in a private bucket. No public URL ever exists for your data.

Install in 3 Steps

No Chrome Web Store needed - load directly in Developer Mode

1

Download & Extract

Click "Download Extension" above and extract the ZIP to a folder of your choice (e.g. C:\qr-file-share-extension\).

2

Open Chrome Extensions

In Chrome, go to chrome://extensions and toggle Developer mode on (top-right switch). Then click "Load unpacked".

3

Select the Folder & Pin

Navigate to and select the extracted folder. The QR File Share extension appears in your extensions list. Click the Extension icon in Chrome → pin it to your toolbar. Done!
